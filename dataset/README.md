# 📊 Dataset - Работа с данными

Модуль для загрузки, обработки и обогащения данных о коммерческой недвижимости.

## 📁 Структура

```
dataset/
├── collection/             # Сбор и парсинг данных
│  ├── avito/              # Обработка Avito данных
│  ├── minjkh/             # MinZhKH реестр
│  └── poi/                # Points of Interest
├── aggregation/           # Агрегация данных
├── data/                  # Хранилище данных
│  ├── dataset_final.json  # Финальный датасет
│  └── samples/            # Примеры данных
└── README.md
```

## 📥 Источники данных

### 1. Avito (avito/)
- **Источник**: Выгрузка объявлений с Avito
- **Формат**: Excel (prodam.xlsx, sdam.xlsx)
- **Обработка**: 
  - Извлечение площади из Параметры
  - Нормализация цен
  - Фильтрация выбросов

**Файлы:**
- `parse_excel.py` - парсинг Excel
- `process_prodam.py` - обработка продажи
- `process_sdam.py` - обработка сдачи
- `merge_datasets.py` - объединение
- `fix_json_format.py` - преобразование для модели

### 2. MinZhKH (minjkh/)
- **Источник**: Реестр жилого фонда
- **Данные**: Здания, квартиры, характеристики
- **Обогащение**: Жилфонд признаки

### 3. POI (poi/)
- **Источник**: OpenStreetMap
- **Данные**: Аптеки, школы, магазины, etc.
- **Признаки**: Расстояния на 6 радиусов (50м-1км)

## 📊 Структура данных

Финальный JSON содержит:

### Базовые поля
- `Цена` - цена за м²
- `Общая площадь` - площадь в м²
- `Район` - административный район
- `Этаж`, `Этажность здания` - положение
- `Дата` - дата объявления

### POI признаки (161)
```
{poi_type}{radius}    # Количество POI в радиусе
{poi_type}MIN         # Минимальное расстояние до POI
```
- 26 типов POI
- 6 радиусов: [50, 100, 150, 300, 500, 1000] м

### Признаки соседей (3)
- `ЦенаNeighborAvg` - средняя цена 3 ближайших
- `ЭтажNeighborAvg` - средний этаж соседей
- `NearestNeighborDistance` - расстояние до ближайшего

### Жилфонд признаки (8)
- `Квартир200`, `Квартир500` - количество кв.
- `Площадь200`, `Площадь500` - общая площадь
- `Год200`, `Год500` - средний год постройки
- `Домов200`, `Домов500` - количество зданий

## 🔄 Конвертация Excel → JSON

### Использование fix_json_format.py:

```python
from dataset.collection.avito.fix_json_format import fix_object

# Преобразование одного объекта
fixed = fix_object(excel_row_dict)
```

**Что делает:**
1. Извлекает площадь из Параметры (если нужно)
2. Пересчитывает цену в руб/м²
3. Добавляет ВСЕ POI поля (даже если 0)
4. Конвертирует MIN расстояния в int
5. Устанавливает координаты = null

### Примеры размеров файлов:
- Raw Excel: 1.8 MB
- Обогащенный JSON: 10-12 MB
- Model-ready JSON: 5.4 MB

## 📈 Обработка данных

### Этап 1: Парсинг
```
Excel → JSON (листы как ключи)
```

### Этап 2: Нормализация
```
JSON → извлечение площади
     → пересчет цены
     → фильтрация выбросов
```

### Этап 3: Обогащение (опционально)
```
JSON → POI данные (OSM)
    → жилфонд (MinZhKH)
    → соседи (NN features)
```

### Этап 4: Форматирование
```
JSON → формат модели (fix_json_format)
    → готово к ML
```

## 🎯 Быстрый старт

### Загрузить через UI:
1. Открыть "📥 Конвертер Excel"
2. Загрузить .xlsx файл
3. Скачать готовый JSON

### Программно:
```python
import pandas as pd
from dataset.collection.avito.fix_json_format import fix_object

df = pd.read_excel('prodam.xlsx')
data = df.to_dict('records')

formatted = [fix_object(obj) for obj in data]
```
