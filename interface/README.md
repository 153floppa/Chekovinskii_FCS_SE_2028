# 🎨 Interface - Streamlit приложение

Веб-интерфейс для анализа и прогнозирования цен коммерческой недвижимости.

## 📁 Структура

```
interface/
├── app.py              # Главное приложение
├── utils.py            # Утилиты обработки данных
└── README.md
```

## 🚀 Запуск

```bash
streamlit run interface/app.py
```

Открыть: http://localhost:8501

## 📑 Вкладки

### 1️⃣ 🎯 Топ недооцененных объектов

**Что делает:**
- Загружает JSON с объектами недвижимости
- Анализирует недооценку каждого объекта
- Показывает лучшие инвестиционные возможности

**Элементы:**
- Загрузка JSON файла
- Таблица объектов с недооценкой
- Фильтры по округам и районам
- Чарты распределения цен
- Экспорт в CSV/JSON

**Использование:**
```
1. Загрузи dataset_final.json или другой JSON
2. Выбери объект из таблицы
3. Посмотри недооценку в % и сумме
4. Анализируй по районам
5. Экспортируй результаты
```

### 2️⃣ 📊 Модель и метрики

**Что показывает:**
- Качество обученной модели CatBoost
- Метрики на тренировочных данных
- Важность признаков

**Метрики:**
- **R²** - объясненная дисперсия
- **MAPE** - средняя абсолютная ошибка в %
- **MAE** - средняя ошибка в руб/м²
- **RMSE** - корневая средняя ошибка

**Визуализация:**
- Scatter plot: предсказание vs реальность
- Top-20 важных признаков
- Идеальная линия предсказания

**Интерпретация:**
```
R² > 0.8  → отличная модель
R² > 0.6  → хорошая модель
R² > 0.4  → приемлемая
```

### 3️⃣ 🔍 Аналитика объекта

**Возможности:**
- Загрузка конкретного объекта
- AI-анализ от OpenAI
- Выявление ключевых факторов
- Оценка потенциала развития

**Процесс анализа:**
```
1. Выбрать объект (из предыдущей вкладки)
2. Нажать "Получить анализ"
3. API отправит запрос в OpenAI
4. Получить:
   - Оценка недооценки
   - Ключевые факторы цены
   - Потенциал развития
   - Рекомендация (купить/продать)
```

**Кэширование:**
- Результаты анализа сохраняются
- Повторная загрузка = без API запроса

### 4️⃣ 📂 Загрузка аналитики

**Функциональность:**
- Импорт данных для анализа
- Расчет оптимальных разбиений
- Анализ профитабельности

**Этапы:**
```
1. Загрузить Excel (проданные/сданные)
2. Выбрать параметры разбиения
3. Система найдет оптимальное разбиение
4. Посмотреть результаты:
   - Увеличение стоимости
   - Профитабильность в %
   - Время окупаемости
5. Экспортировать таблицу
```

**Фильтры:**
- По округам
- По типам объектов
- По площади
- По профитабельности

### 5️⃣ 📥 Конвертер Excel

**Преобразование:**
```
Excel (prodam.xlsx) 
  ↓
JSON (список объектов)
  ↓
Форматирование (fix_json_format.py)
  ↓
JSON model-ready (готово для модели)
```

**Что происходит:**
1. Загрузка Excel файла
2. Извлечение площади из Параметры
3. Нормализация цен (цена/м²)
4. Добавление всех POI полей
5. Преобразование расстояний в int
6. Установка координат = null

**Результат:**
- JSON файл готов к использованию
- Все 212+ полей присутствуют
- Правильные типы данных

## 📈 Производительность

- Загрузка данных: < 1 сек
- Расчет метрик: 5-10 сек
- Анализ объекта (OpenAI): 10-30 сек
- Разбиения: 30-60 сек для 1000 объектов

## 🐛 Типичные проблемы

**"Модуль форматирования недоступен"**
→ Проверить наличие `dataset/collection/avito/fix_json_format.py`

**"Ошибка при загрузке модели"**
→ Проверить наличие `model/regressors/catboost_regressor.py`

**Медленная работа**
→ Кэширование включено, проверить RAM и CPU
