## 🎯 Текущая модель: CatBoost Regressor

### Описание

**CatBoost** (Categorical Boosting) - это градиентный бустинг на решающих деревьях, разработанный Яндексом.

**Преимущества для нашей задачи:**
- Хорошо работает с категориальными признаками
- Быстро обучается
- Меньше переобучения
- Встроенная обработка категорий

### Метрики модели

```
R² Score:        0.45-0.55     (объясненная дисперсия)
MAPE:            15-25%        (средняя % ошибка)
MAE:             50,000 ₽/м²   (средняя ошибка)
RMSE:            75,000 ₽/м²   (корневая ошибка)
```

### Использование

```python
from model.regressors.catboost_regressor import get_model

# Загрузить модель
model = get_model('catboost_regressor')

# Предсказать
from catboost import Pool
pool = Pool(X_test, cat_features=['Район', 'Вид объекта'])
predictions = model.predict(pool)
```

## 📊 Признаки модели

### Входные признаки (~200)

**Базовые:**
- Общая площадь
- Этаж, Этажность здания
- Дата объявления
- Район, Вид объекта

**POI (161 признак):**
```
{категория}{радиус}    # Кол-во POI в радиусе
{категория}MIN         # Мин расстояние до POI
```

Примеры:
- Аптека50, Аптека100, ... Аптека1000
- АптекаMIN
- Школа50, Школа100, ... Школа1000
- ШколаMIN
- и т.д. для 26 категорий

**Соседи (3 признака):**
- ЦенаNeighborAvg - средняя цена 3 ближайших
- ЭтажNeighborAvg - средний этаж соседей
- NearestNeighborDistance - до ближайшего

**Жилфонд (8 признаков):**
- Квартир200, Квартир500
- Площадь200, Площадь500
- Год200, Год500
- Домов200, Домов500

### Целевая переменная

**Цена за м²** (нормализованная цена)
```
Цена за м² = Общая цена / Общая площадь
```

## 📈 Важные признаки

**Top-20 по корреляции:**

```
1. avg500              0.466  (средняя цена соседей)
2. avg1000             0.410  (средняя цена соседей)
3. Школа1000           0.158  (школы в 1км)
4. ВУЗ1000             0.142  (ВУЗы в 1км)

```

**Вывод:**
- Цена соседей - самый важный признак
- POI признаки помогают, но слабо
- Категориальные признаки (Район, Вид) тоже важны

## 🔄 Процесс предсказания

```
1. Получить объект (dict с признаками)
   ↓
2. Привести к формату модели (fix_json_format)
   ├─ Все 212 полей заполнены
   ├─ Правильные типы данных
   └─ Нулевые значения для отсутствующих
   ↓
3. Создать Pool для CatBoost
   ├─ Выделить категориальные признаки
   └─ Сопоставить с признаками обучения
   ↓
4. Получить предсказание
   ├─ price_per_sqm (за м²)
   └─ full_price = price_per_sqm * area
   ↓
5. Интерпретировать результат
   ├─ Сравнить с реальной ценой
   ├─ Расчитать недооценку
   └─ Сделать рекомендацию
```

## 🚨 Ограничения модели

1. **Специфичность географии**
   - Модель обучена на конкретном городе
   - Может не работать в других городах

2. **Зависимость от Avito**
   - Цены берутся из объявлений
   - Реальные сделки могут отличаться

3. **Временные тренды**
   - Модель не учитывает тренды со временем
   - Требует переобучения со временем

4. **Категории объектов**
   - Лучше работает для типовых объектов
   - Хуже для уникальных объектов
